All1200 original REFUGE GT masks, encoded losslessly as PNG.
Pixel labels:0=cup,128=disc rim,255=background. Full disc includes cup and rim.
GT CDR is cup occupied-row height divided by full-disc occupied-row height.
The ZIP retains gt_mask_manifest.csv and flat mask filenames for compatibility with V8 Cell17.
Clinical GT class comes from the dataset labels; it is not calculated from GT CDR.
The existing Drive archive filename is retained so current Colab paths continue to work.
